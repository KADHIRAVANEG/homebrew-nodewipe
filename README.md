## Installation via Homebrew (macOS & Linux)

### Option 1: Direct Single-Command Install (Recommended)
```bash
brew install kadhiravaneg/nodewipe/nodewipe
```

### Option 2: Add Tap and Install
```bash
brew tap kadhiravaneg/nodewipe
brew install nodewipe
```

## Updating
```bash
brew update
brew upgrade nodewipe
```

## Quick Start
```bash
# Scan and identify reclaimable dev artifacts across 39+ ecosystems
nodewipe scan

# Launch interactive terminal TUI with dry-run mode
nodewipe

# Run system-wide storage analysis across all toolchains
nodewipe doctor ~
```
